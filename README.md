# hotelreservas

## Descrição

Sistema de reservas de hotel desenvolvido para gerenciamento de quartos e reservas, permitindo cadastrar quartos e realizar reservas de hóspedes.

## Tecnologias Utilizadas
- VS Code
- MySQL 8.0
- Node.js 22.0
- Express.js 5.0

### Linguagens Utilizadas
- JavaScript
- SQL
- HTML
- CSS
