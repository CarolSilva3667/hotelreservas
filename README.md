# hotelreservas

## Descrição

Sistema de reservas de hotel desenvolvido para gerenciamento de quartos e reservas, permitindo cadastrar quartos e realizar reservas de hóspedes.

## Tecnologias Utilizadas
- VS Code
- MySQL 8.0
- Node.js 22.0
- Express.js 5.0

### Linguagens Utilizadas
- JavaScript
- SQL
- HTML
- CSS

## Prints das Telas
Estão anexadas não pasta "wireframes"

## Passo a Passo de Execução do Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/CarolSilva3667/hotelreservas
   ```

2. Acesse a pasta da API:
   ```bash
   cd api
   ```

3. Instale as dependências:
   ```bash
   npm install
   ```

4. Configure o banco de dados MySQL e execute o script SQL disponível na pasta `docs`.

5. Inicie o servidor:
   ```bash
   npm start
   ```

6. Abra o front-end localizado na pasta `web`.

7. Utilize o sistema para cadastrar quartos e realizar reservas.
